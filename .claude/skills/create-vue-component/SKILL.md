# Vue 컴포넌트 파일 생성

사용자가 요청한 경로($ARGUMENTS)에 아래 템플릿으로 `.vue` 파일을 만든다.

## 템플릿

이 내용(@refs/Template.vue)을 한 글자도 바꾸지 말고 그대로 쓴다. 사용자가 따로 요청하지 않는 한 컴포넌트 이름, props, 예시 마크업 등을 임의로 채워 넣지 않는다. 빈 상태에서 직접 코드를 쓰기 시작하는 것이 이 스킬의 목적이다.

## 경로 결정

위에서부터 순서대로 적용한다.

1. 사용자가 확장자까지 붙여서 파일명을 정확히 적어 주면 그 표기를 그대로 존중한다. 2번과 3번은 건너뛴다.
1. 파일명을 소문자 한 단어로만 주면 PascalCase로 바꾼다.
1. 확장자가 없으면 `.vue`를 붙인다.
1. 폴더 경로가 없으면 `src/components`에 만든다. 폴더를 지정했는데 `src`로 시작하지 않으면 `src` 아래 경로로 본다.
1. 대상 폴더가 없으면 `mkdir -p`로 만든 뒤에 파일을 쓴다.
1. 파일명을 알 수 없으면(인자가 비었거나 폴더만 지정한 경우) 파일 이름을 되묻는다. 임의로 정하지 않는다.

### 한글 소리 표기 해석

사용자가 영어 단어를 한글 소리 나는 대로 적는 경우가 많다. 아래처럼 읽는다.

| 사용자 표기 | 실제 |
| --- | --- |
| 에스알씨 | `src` |
| 컴포넌츠, 컴포넌트 폴더 | `components` |
| 앱 뷰, 앱뷰 | `App.vue` |
| 메인 | `main` |
| 뷰 파일, 뷰 컴포넌트 | `.vue` 파일 |

### 예시

| 요청 | 결과 경로 |`
| --- | --- |
| `src/App.vue` | `src/App.vue` |
| `에스알씨 폴더에 앱 뷰 컴포넌트 파일 만들어 줘` | `src/App.vue` |
| `Header` | `src/components/Header.vue` |
| `header 컴포넌트` | `src/components/Header.vue` |
| `layouts/the-footer.vue` | `src/layouts/the-footer.vue` |
| (인자 없음) | 파일 이름을 되묻는다 |

## 파일 쓰기

- 기존 파일이 있으면 무조건 덮어쓴다. 덮어쓸지 말지 확인하는 질문은 하지 않는다. 작업하던 예제를 지우고 빈 상태로 되돌리는 것이 자주 쓰는 흐름이라, 여기서 멈춰 물어보면 오히려 방해가 된다.
- 여러 파일을 한 번에 요청하면 전부 만든다.

## 결과 보고

- 만든 파일 경로를 알려준다.
- 덮어쓰기 전에 기존 내용을 확인해서, 템플릿과 다른 코드가 들어 있었다면 어떤 내용을 덮어썼는지 한 줄로 알려준다. 되돌릴 기회를 주기 위한 사후 보고이고, 작업을 멈추는 확인 절차가 아니다.
